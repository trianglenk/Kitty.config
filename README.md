<h1 align="center">Kitty terminal Customization</h1>


![Скриншот kitty](./изображение.png)
Основные возможности

    шрифт JetBrainsMono Nerd Font;
    тёмная цветовая схема;
    палитра Nord;
    полупрозрачный фон;
    панель вкладок сверху;
    вкладки выровнены по центру;
    стиль вкладок Powerline;
    автоматическое открытие окон и вкладок в текущей директории;
    несколько раскладок окон;
    горячие клавиши для навигации;
    копирование через Ctrl+C;
    вставка через Ctrl+V.

Горячие клавиши
Буфер обмена
Сочетание	Действие
Ctrl+C	Копировать выделенный текст
Ctrl+V	Вставить текст из буфера
Ctrl+Shift+C	Прервать текущую команду
Окна
Сочетание	Действие
Ctrl+Shift+Enter	Новое окно в текущей директории
Ctrl+Shift+]	Следующее окно
Ctrl+Shift+[	Предыдущее окно
Ctrl+Shift+W	Закрыть окно
Вкладки
Сочетание	Действие
Ctrl+Shift+T	Новая вкладка в текущей директории
Ctrl+Shift+Right	Следующая вкладка
Ctrl+Shift+Left	Предыдущая вкладка
Ctrl+Shift+Q	Закрыть вкладку
Раскладка окон
Сочетание	Действие
Ctrl+Shift+L	Следующая раскладка
Ctrl+Alt+T	Раскладка Tall
Ctrl+Alt+S	Раскладка Stack
Размер шрифта
Сочетание	Действие
Ctrl++	Увеличить шрифт
Ctrl+-	Уменьшить шрифт
Ctrl+0	Сбросить размер шрифта
